# Idle-Breakout-Save-Code-Website

This is a web page implementation of my python idle breakout save code generator. its also my first time doing web dev, and using html, css, and javascript.

# How it works

It has boxes for every stat, and you can customize them at will. then when you click generate save code, a js implementation of my save code gen puts your inputs into a csv string, then turns it into idle breakout readable base 64 using javascripts ("btoa")
